# 보안 규칙 (1화면 요약)

> 정본: `CLAUDE.md` §10 · `ADR-002`(세션 인증) · `ADR-004`(전략 IP 분리).

## 시크릿

* `.env`를 **읽지 않는다**. 커밋하지 않는다. 값을 로그·문서·커밋 메시지에 옮기지 않는다.
* `docs/_private/`를 **읽지 않는다** (ADR-004 전략 IP).
* `.env.example`에는 실제 값이 아니라 자리표시자만 둔다.
* 코드에 시크릿을 하드코딩하지 않는다. 전부 환경변수로 주입한다.

## 인증 (ADR-002)

* **Session 단일 전략.** JWT · DRF Token · Knox를 도입하지 않는다. 새 인증 패키지는 새 ADR이 필요하다.
* 세션 쿠키: `sessionid`, **HttpOnly + Secure + SameSite=Lax**, 14일, 슬라이딩 갱신. `Secure`는 localhost 외 전 환경 필수.
* **로그아웃은 서버 세션 레코드를 삭제**하고 `Set-Cookie: sessionid=; Max-Age=0`을 함께 보낸다. 클라이언트 쿠키 삭제에만 의존하지 않는다.
* Google OAuth 콜백은 **같은 세션 모델을 재사용**한다. 병렬 인증 경로를 만들지 않는다. 계정 연결은 검증된 이메일 기준.
* 비밀번호는 Django 기본 **PBKDF2**. 평문·가역 암호화 저장 금지.
* **CSRF는 모든 상태 변경 엔드포인트에서 켠다.** 클라이언트는 `csrftoken` 쿠키를 읽어 `X-CSRFToken` 헤더로 보낸다.

## 접근 제어

* 사용자 소유 데이터는 **객체 수준 접근 제어**를 강제한다. 쿼리셋 필터로 끝내지 말고 상세 조회에서도 소유권을 검사한다.
* **사용자에게는 `APPROVED` 조언만 보인다.**
* 관리자 전용 동작을 공개 엔드포인트로 노출하지 않는다.
* 직렬화 **전에** 접근 제어를 적용한다.

## 응답 필드

* ModelSerializer로 모든 필드를 무심코 반환하지 않는다. **응답 필드는 의도적으로 고른다** (§8).
* 절대 노출 금지: `password`, `is_staff`, `is_superuser`, **`intended_lane`**.
* **`intended_lane`**은 신청자가 밝힌 의향일 뿐 자격 등급이 아니다. 공개 응답·타 사용자 표시·권한 키 어디에도 쓰지 않는다. 관리자 심사 도구에서만 보인다.
* 목록 API는 표시에 필요한 필드만. 큰 텍스트 필드를 넣지 않는다.

## 로깅

개인정보·시크릿·세션 ID를 로그에 남기지 않는다. 에러 응답에 스택 트레이스나 내부 경로를 노출하지 않는다.

## 알려진 갭

**브루트포스 방어(IP + 계정 기반 rate limit)는 Phase 3 이월이다.** Phase 2에서는 갭을 문서에 명시하는 것으로 갈음한다 (§10). 스모크 테스트 노트에 기록 예정.

## 운영

* `DEBUG`는 운영 설정에서 절대 true가 아니다.
* `ALLOWED_HOSTS`는 로컬 외에서 명시적이어야 한다. `config/settings/prod.py`는 비어 있으면 `RuntimeError`를 던진다.
* 컨테이너는 비루트로 실행한다 (uid 10001).
